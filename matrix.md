This is a list of behaviours that we expect SRP engineers who deliver projects to remote international clients to follow
we only write down the non-obvious ones.

1. Coaching: 
a. Snr: Can move a junior through do-watch, do-help, help-do, watch-do 
b. Snr: asks coaching questions to juniors to help them think through a problem

2. Communicating:
a. Jnr: Daily updates a written to do list.
b. Mid: Sends team and client a daily written status update - we update BEFORE the client has to ask
c. Mid: Provide the client "A or B" options when key decisions need to be made, in both written and verbal form. 

3. Engineering:
a. Mid: Keeps the project AI harness up to date
b. Jnr: Uses AI to produce <1000line PRs that are validated, tested. 
c. Jnr: Can articulate the difference between integration, interface, unit tests, and articulate the test coverage and methods in the current project 
d. Mid: Ensures tests are updated every time a bug is discovered.

4. Deliver value to the client
a. Snr: Can articulate the business strategy of the client. Knows the revenue and profit goals for the next year and how they connect to the current system. 
b. Mid: define and maintain SMART milestones
c. Mid: Can explain a task or milestone in business/project terms
d. Jnr: Ensures that no work is released without proper internal QA and client approval
e. Jnr: Follows the release process every time
f. Mid: builds effective release process that fits the client and project needs
